# Name Clearance — Glassface Lane

**Date:** 2026-09-18
**Worker:** Digital Licensing + Naming (ATHENA Glassface lane)
**Method:** web-only collision search (web search engine results, trademark-aggregator pages).
**Limits (read first):** This is NOT a trademark clearance opinion and is NOT a substitute for
USPTO TESS review or trademark counsel. USPTO TESS is browser-hard from this environment, so no
direct TESS serial/class search was run — findings come from web search results and aggregator
pages, which may be stale or incomplete. If CWI ever files a mark, retain counsel.

## Candidates evaluated

### Candidate 1: "Glassface" (working title)

- **USPTO:** aggregator TrademarkTok reports **GLASSFACE — Serial No. 79197500 — owner Profiler GmbH —
  category "Electronic Machines" — status: Registered** (page last crawled ~160 days ago; filing
  date noted Jan 06, 2017 in prosecution history).
- **EUIPO:** Glassface EUTM application **013958673** (filed 2015-04-16, classes incl. Computer &
  Software Services and Computer Product/Electrical & Scientific Products) — status: **Registration
  expired**.
- **App/product web search:** no iOS/Android app or smart-glasses product named Glassface surfaced.
- **Assessment:** RED FLAG. A live US registration in "Electronic Machines" for the identical word
  is a collision in exactly the right class neighborhood for an eyewear-adjacent software agent.
  Even though we are not selling hardware, a wearable-software product under "Glassface" invites a
  conflict claim. **Do not ship this name.**

### Candidate 2: "KingCode Lens"

- **Trademark web search:** no trademark hits for the composite "KingCode Lens". Bare "KingCode"
  hits are out-of-class and out-of-market: **Kingcode Elite 50EC** (Greenlife Crop Protection,
  agricultural insecticide — pesticide class, Africa) and **kingcode.uk** ("King Code" web-dev
  company, UK). Neither is software/wearables/AI.
- **App/product web search:** no app, glasses product, or AI assistant named KingCode or
  KingCode Lens surfaced.
- **Assessment:** CLEAN on web-only check. The composite ties the product to the existing KingCode
  brand (Black's named agent identity; the wake phrase "Hey KingCode" becomes "Hey KingCode" +
  "Lens"). Same-brand family as the Agent Deck line. This is the recommended name.

### Candidate 3: "Facet"

- **Smart-glasses web search:** no smart-glasses product, app, or assistant named Facet surfaced.
- **Assessment:** CLEAN on web-only check, but **weaker recommendation**: "Facet" is a common
  dictionary word with broad use across classes (unexamined in this pass) and it carries zero brand
  equity — it tells no one this is KingCode. Kept as a fallback only.

## Invocation phrase: "Hey KingCode" (custom) / "ask KingCode" (routed)

- **Web search for "Hey KingCode":** no collisions with any existing voice assistant or wake word.
- **"Hey Meta"** is Meta's own wake phrase on Meta glasses for Meta AI — we do not touch it.
- **Why not "Muse":** Meta has an AI product named **Muse**; using "Muse" as a spoken assistant
  name would collide with Meta's own product and risk endorsement/confusion claims. "Hey KingCode"
  deliberately avoids it. Cleared.

## Recommendation

**Final product name: KingCode Lens.** Wake phrase stays "Hey KingCode" (custom path) / "ask
KingCode" (routed path). Rationale:

1. "Glassface" is blocked by a live US mark (79197500) in the relevant class.
2. "KingCode Lens" has no web-surfaced collisions and compounds CWI's existing brand equity
   (KingCode is the public agent identity; the lens is where it lives).
3. Avoids the Meta collision that killed "Muse".

**Coordination note:** a sibling worker is building repo `cwi-glassface`. Final naming authority
sits with the lane coordinator — if the product name becomes KingCode Lens, the repo should be
renamed/aliased to match (suggested: `cwi-kingcode-lens`) rather than shipping a registered mark
in the repo name. Coordinator decides.

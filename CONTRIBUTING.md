# Contributing to KingCode Lens

KingCode Lens is **proprietary software** © 2026 Cumulative Web Inc.
There is no public pull-request workflow: we do not accept PRs from outside
CWI, and there is no contributor license agreement to sign.

## What you CAN do

- **Report bugs** — open a GitHub issue with steps to reproduce, expected
  vs. actual behavior, and your browser/Node version.
- **Request features** — open an issue describing the use case. The lens
  simulator's parity with Meta's official extension is the north star;
  hardware-dependent asks stay out until real hardware exists in the lab.
- **Evaluate freely** — personal, development, and evaluation use is free
  under the license. Fork on GitHub for your own evaluation if you like.

## What you CANNOT do

- Submit pull requests (they will be closed unmerged — nothing personal,
  it's the license model).
- Redistribute, mirror, or republish the code (see `LICENSE` §4).
- Use CWI's or KingCode Lens's name, logo, or branding for your own
  products.

## If you work at CWI

Internal contributors: feature branch → `node --test` green (117 tests) →
independent verification of any vendor-behavior claim → merge to main.
Every product-facing claim needs a receipt. See `docs/VERIFICATION-2026-09-18.md`
for the evidence standard.
